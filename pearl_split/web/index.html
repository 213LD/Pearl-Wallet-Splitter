📘 WxPusher 配置指引：
1. 微信登录 https://wxpusher.zjiecode.com，新建应用获取 AppToken。
2. 在应用下创建一个主题 (Topic)，把订阅二维码发到朋友群让大家微信扫一下，填入上方 Topic ID 即可群发。
